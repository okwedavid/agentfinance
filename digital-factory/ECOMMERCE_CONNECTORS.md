## 🔌 How to Connect in n8n (Windows 11 Local)

### 1. Gumroad (Recommended #1)

1. Go to https://gumroad.com/settings/advanced -> Create Application
2. Get Access Token
3. In n8n:
   - Node: **HTTP Request**
   - **Credential**: Header Auth -> `Authorization: Bearer YOUR_TOKEN`
   - Method: POST `https://api.gumroad.com/v2/products`
   - Body:
     ```json
     {
       "name": "FreelancerFlow AI™ - Client OS",
       "price": 49,
       "custom_summary": "Get 3-5 high-ticket clients in 30 days...",
       "custom_permalink": "freelancerflow-ai",
       "access_token": "YOUR_TOKEN"
     }
     ```
   - After create, upload file: POST `/v2/products/{id}/files` with multipart

**Tips:**
- Enable Gumroad Discover for organic traffic
- Use this factory's `gumroad.md` as description
- Price tiers: Create variants via API or dashboard: $19 Basic (PDF only), $49 Standard (Full), $99 Premium + 1h call

### 2. Shopify (Recommended for brand)

1. In Shopify Admin -> Apps -> Develop Apps -> Create App
2. Scopes: `write_products, read_products, write_files`
3. Install and get `SHOPIFY_ACCESS_TOKEN`
4. n8n:
   - Use built-in **Shopify node** (Product -> Create)
   - Domain: `your-store.myshopify.com`
   - Body from `shopify.html` file generated by factory
   - Price from evaluation
   - After product, add Digital Downloads app or use metafield for file link (host ZIP on S3/Drive)

### 3. Etsy (Best for Templates, Planners)

1. Go to https://www.etsy.com/developers -> Create App
2. Get API Key
3. n8n Etsy Node:
   - OAuth2 flow (connects your shop)
   - Action: Create Listing
   - Title: Max 140 chars, from `listing.txt` (our factory makes Etsy-optimized title)
   - Tags: Use `etsy_tags` (13 tags, 20 chars max) - critical for SEO!
   - Type: Digital, Quantity 999
   - Files: Upload ZIP to Etsy (manual or via API: `uploadListingFile`)

**Pricing:** $0.20 listing fee, last 4 months. Sells well for $9-$29.

### 4. WooCommerce (Own Website, 0 Marketplace Fees)

1. In WP Admin -> WooCommerce -> Settings -> Advanced -> REST API -> Add Key (Read/Write)
2. n8n WooCommerce node:
   - URL: `https://yourdomain.com`
   - Consumer Key/Secret
   - Create Product: Name from brand_name, virtual=true, downloadable=true
   - Short description from our `short_description`
   - Use `seo.txt` for Yoast SEO field

**Advantage:** 100% margin minus Stripe (2.9%). Bundle easily.

### 5. Payhip (Beginner Friendly)

API limited. Use:

- n8n HTTP Request: POST `https://payhip.com/api/v1/products` (if enabled on your account)
- Else: Manual upload, but automate listing copy via n8n "Write File" -> copy-paste ready `payhip.txt`

Payhip has **built-in affiliate** + VAT handling. Great for EU.

### 6. Ko-fi Shop

1. Ko-fi -> Settings -> API
2. Get Verification Token
3. n8n Webhook:
   - Ko-fi supports webhooks for sales notifications -> n8n webhook node listens for sales, triggers email sequence
   - For product creation: No public API, use HTTP Request scraping or manual: Use our `gumroad.md` adapted

**Why Ko-fi:** Lower friction purchase ($3-$50), audience trusts it.

### 7. LemonSqueezy (Modern, Software)

1. https://app.lemonsqueezy.com/settings/api
2. Create API Key
3. n8n HTTP Request:
   ```
   POST https://api.lemonsqueezy.com/v1/products
   Headers: Authorization: Bearer API_KEY, Accept: application/vnd.api+json
   Body: { data: { type: products, attributes: { name, description, price: 4900 (cents) } } }
   ```
4. Upload files: POST `/v1/files` then attach to product variant

**Advantage:** Handles global tax, modern checkout, license keys.

### 8. Stripe Payment Links (Direct - No Marketplace)

If you want **zero platform** and direct to bank:

- n8n Stripe node: Create Product -> Create Price -> Create Payment Link
- Use `checkout session` with success URL delivering ZIP via email (SendGrid node in n8n)

## 🤖 Automation Flow in n8n (Windows 11)

Your local n8n runs this:

```
ZIP Created
  ↓
IF Gumroad creds exist? → Create Gumroad product → Upload ZIP
  ↓
IF Shopify creds exist? → Create Shopify product + add to Digital Downloads API
  ↓
IF Etsy OAuth connected? → Create Etsy listing (draft) → Add tags → Upload files
  ↓
IF WooCommerce creds? → Create Woo Product (draft)
  ↓
Slack/Discord notification: "New product {brand_name} published"
```

All publishing assets are in `Publishing/` folder: you already have description, SEO, social posts.

### n8n Credentials to Setup (http://localhost:5678):

- **Header Auth**: Groq (`Authorization: Bearer gsk_...`)
- **Shopify API**: `your-store.myshopify.com` + Access Token
- **Etsy OAuth**: Connect via n8n Etsy node
- **WooCommerce**: Consumer Key/Secret
- **Gumroad**: Access Token in env or Header Auth
- **Slack/Discord**: For notifications

### Windows 11 Specific:

- Factory root: `C:\DigitalFactory` (your n8n Read/Write File nodes use this path)
- n8n installed via `npm i -g n8n`
- Run `n8n start` -> open `http://localhost:5678`
- Workflows live in `C:\Users\YOURNAME\.n8n\workflows` but you import from `digital-factory/n8n-workflows/`
